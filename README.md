# SoMembers

Member and company directory for [SoCentral](https://www.socentral.no), built with Astro. Data is fetched from the OfficeRnD coworking platform at build time - there is no client-side API access.

Live at: https://medlemmer.socentral.no

## Commands

```sh
npm install        # Install dependencies
npm run dev        # Start dev server at localhost:4321
npm run build      # Build static site to ./dist/
npm run preview    # Preview production build locally
```

## Architecture

Static site generated by Astro 5. All data fetching happens at build time via `src/content.config.ts`, which:

1. Authenticates against OfficeRnD's OAuth2 endpoint using `CLIENT_ID` and `CLIENT_SECRET`
2. Paginates through the OfficeRnD REST API (members and companies)
3. Filters out hidden profiles based on portal privacy settings
4. Proxies images through ImageKit (`ik.imagekit.io/socentral`)
5. Sorts results: profiles with images first, then by newest creation date

## Structure

```
src/
  content.config.ts        # Data loaders (OfficeRnD API)
  layouts/
    Layout.astro            # Shell: header, footer, global CSS
  pages/
    index.astro             # Members grid
    companies.astro         # Companies grid
    members/[slug].astro    # Member detail page
    companies/[slug].astro  # Company detail page
public/
  logo.png
  favicon.png
```

## Environment variables

Create a `.env` file in the project root:

```
CLIENT_ID=...
CLIENT_SECRET=...
```

These are used exclusively at build time to authenticate with OfficeRnD. On Netlify, set them under Site settings - Environment variables.

## Deployment

Hosted on Netlify, triggered on push to `master`.

- Build command: `npm run build`
- Publish directory: `dist`
